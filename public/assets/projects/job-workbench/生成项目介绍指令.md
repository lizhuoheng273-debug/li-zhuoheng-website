# 指令：为项目生成面向面试官的 MD 介绍文档（含多模块截图）

> 把本文件全文（含文末截图脚本模板）发给目标 AI，将其中「项目输入」的路径替换成目标 AI 可访问的实际路径即可。

## 任务
为指定项目生成一份面向**秋招面试官**的精简介绍文档（Markdown），并附带**多张不同模块的界面截图**，最终把 MD 与图片放入同一文件夹并打包成 zip 交付。

## 项目输入（按实际情况替换路径）
- 项目根目录：C:/简历/秋招工作台/
- 前端页面：frontend/index.html（自包含单文件，浏览器打开即为完整应用）
- 后端代码：backend/（main.py 入口、db.py 数据层、scoring.py 评分、generate_html.py 静态页生成、import_to_workbench.py 扫描入库）
- 数据：backend/workbench.sqlite3（岗位 / 信源数据）
- 线上地址：https://lizhuoheng273-debug.github.io/workbench/

## 产出要求

### 1. 文档 `项目介绍.md`（正文 ≤ 400 字中文，信息密度高）
结构固定如下：
- **标题 + 一句话定位**（副标题）
- **## 项目背景**：2-3 句动机（解决了什么痛点）
- **## 核心能力**：表格 4-6 行（能力 | 说明）
- **## 技术架构**：一段文字 + 代码块 ASCII 数据流图（从扫描到入库到发布）
- **## 线上地址**：链接一行
- **## 界面截图**：每张图配一行加粗说明（一句话讲清该模块是干什么的）
- **## 项目亮点**：3 条 bullet（面试可展开，突出自动化闭环、可解释评分、零部署自包含、工程取舍与产品思维）

### 2. 截图 5 张（每张只截视口 1440×950，**不要**整页长图）
| 文件 | 模块 | 说明要点 |
|---|---|---|
| img-tab-all.png | 全部岗位 | 评分/等级/截止日一目了然 |
| img-tab-fav.png | 收藏 | 重点岗位 |
| img-tab-kanban.png | 看板 | 按投递进度流转 |
| img-tab-prep.png | 面试准备 | 按岗位准备清单 |
| img-tab-source.png | 信源 | 招聘信息源管理 |

截图方式：无头浏览器（Node + puppeteer-core 驱动系统 Edge）打开本地 index.html，点击左侧导航 `.mod-item[data-m="xxx"]` 切换模块后截图。**截图脚本模板见文末**；若环境缺依赖，先 `npm i puppeteer-core`（用系统浏览器，无需下载 Chromium）。

### 3. 图片引用与打包
- MD 中图片用**相对路径**引用（如 `![全部岗位](img-tab-all.png)`）。
- MD 与全部图片放**同一文件夹**。
- 再打包 zip，**MD 与图片直接放 zip 根目录**（解压即用，不要套一层文件夹）。

## 文风与边界
- 读者是秋招面试官：篇幅精简、信息密度高、突出技术深度与产品思维。
- **只写事实，不虚构功能**；不确定的细节不要编造。

## 截图脚本模板（Node.js，Windows）
```js
const puppeteer = require('puppeteer-core');
(async () => {
  const browser = await puppeteer.launch({
    executablePath: 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe',
    headless: true,
  });
  const page = await browser.newPage();
  await page.setViewport({ width: 1440, height: 950 });
  await page.goto('file:///C:/简历/秋招工作台/frontend/index.html', { waitUntil: 'load', timeout: 30000 });
  await new Promise(r => setTimeout(r, 2000));
  const tabs = [
    ['all',    'img-tab-all.png'],     // 全部岗位
    ['fav',    'img-tab-fav.png'],     // 收藏
    ['kanban', 'img-tab-kanban.png'],  // 看板
    ['prep',   'img-tab-prep.png'],    // 面试准备
    ['source', 'img-tab-source.png'],  // 信源
  ];
  for (const [m, name] of tabs) {
    await page.click(`.mod-item[data-m="${m}"]`);
    await new Promise(r => setTimeout(r, 1200));
    await page.screenshot({ path: `C:/简历/秋招工作台_项目介绍/${name}` });
    console.log('shot', name);
  }
  await browser.close();
  console.log('ALL DONE');
})().catch(e => { console.error('ERR', e.message); process.exit(1); });
```

> 环境提示：Windows 上运行 Node 脚本时，**路径一律用 `C:/...` Windows 风格**（不要用 git-bash 的 `/c/...`，会被转错）；若无法截图请先检查 msedge.exe 路径是否存在。
